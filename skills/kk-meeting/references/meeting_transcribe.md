# 회의 기록으로 회의내용 쓰기 — 글 · 녹음 · 휴대폰/클로바노트 (2026-09-27 사용자 지시)

회의내용은 **실제 회의 기록**에서 가져오는 것이 가장 정확하다. 그래서 회의 주제를 묻기 전에 먼저 기록이 있는지 묻고,
기록이 없을 때만 종전 방식(주제를 묻고 사용자가 직접 쓰거나 Claude 가 과제제안서·보고서로 작성)으로 간다.

## 1. 순서 (건마다 — 같은 날 식당+카페는 한 건)

| 순서 | Claude 가 묻는 말 | 있으면 |
|---|---|---|
| ① 글 | "이 회의 내용을 적어 둔 글이 있나요? 회의 메모, 녹취록, 회의 자료, 휴대폰 녹음 앱이나 클로바노트에서 바꾼 텍스트 무엇이든 파일로 주시거나 붙여 넣어 주세요." | 2절대로 읽어서 5절대로 초안 |
| ② 녹음 | "글이 없으면 회의를 녹음한 파일이 있나요? 있으면 제가 글로 바꿔 요약할 수 있습니다." | 3절 점검 → 이 PC 변환(4절) 또는 휴대폰·클로바노트(6절) |
| ③ 없음 | "9/1 ○○식당 건의 회의 주제를 알려주세요." → "회의내용은 직접 적어 주시겠어요, 아니면 제가 제안서·보고서를 근거로 작성할까요?" | SKILL 단계 5 ③ |

- 여러 건을 처리할 때는 질문을 모아서 한 번에 묻는다(건별 번호를 붙여 "1번 건 메모 있음 / 2번 건 녹음 있음 / 3번 건 없음" 처럼 답받기).
- 사용자가 준 글이 이미 회의록 형태면(제목·내용이 정리돼 있으면) 그대로 쓰고 **고치지 않는다**. 메모·녹취록처럼 정리가 필요한 경우에만 초안을 만든다.

## 2. 글로 된 기록 읽기

| 형식 | 방법 |
|---|---|
| txt · md · 채팅에 붙여 넣은 글 | 그대로 읽는다 |
| pdf | Read 로 바로 읽는다(스캔 이미지 pdf 도 읽힘) |
| docx(워드, Teams 녹취록) · hwpx(한글) · vtt · srt(자막) | `python scripts/transcribe.py text <파일>` → `{kiki_root}\meeting\transcripts\<이름>_회의기록.txt` 를 읽는다(자막 시각표·서식을 빼 글자 수가 줄어든다). 마지막 줄 `[요약] 글 N자` |
| hwp(구형 한글) | 바로 못 읽는다 → "한글에서 다른 이름으로 저장으로 hwpx 나 pdf 로 저장해 주세요" |
| 사진(화이트보드·손글씨 메모) | Read 로 이미지를 읽는다. 글씨가 불확실한 부분은 표시해 확인받는다 |

## 3. 녹음이 있으면 — 이 PC 점검 (`transcribe.py check <녹음 파일>`)
설치 없이 몇 초 만에 이 PC 사양·설치 상태·녹음 길이·녹음 시작 시각을 읽고 권장 경로를 고른다. 마지막 줄 `[요약] 권장 <경로>(대안 <경로>) | 예상 A~B분 | 설치 필요 예/아니오 | 녹음 N분`.

| 권장 | 조건(자동 판정) | 사용자에게 |
|---|---|---|
| `local-gpu` | NVIDIA 그래픽카드(메모리 4GB 이상) | "이 PC 에서 바꿀 수 있습니다. 한 시간 녹음 기준 몇 분 정도입니다." + 처음 한 번 설치 안내(4절) |
| `local-cpu` | 그래픽카드 없음, 물리 코어·메모리 충분, 예상 시간 상한 30분 이하 | "이 PC 에서 바꿀 수 있습니다(예상 A~B분, 그동안 다른 일 하셔도 됩니다)." + 설치 안내 |
| `phone`(대안 `local-cpu`) | 예상 시간이 30~90분이거나 사양이 낮음(메모리 6GB 미만·물리 2코어 이하)·여유 공간 부족·파이썬 3.9 미만 | 6절 안내. 대안이 `local-cpu` 면 "그래도 이 PC 에서 하시겠다면 A~B분 걸립니다" 를 한 줄로 |

- 예상 시간은 공식 벤치마크(가벼운 모델 small, int8, 8스레드 데스크톱에서 13분 녹음 1분 42초)를 바탕으로 코어 수를 반영한 **추정**이다. 실제 시간은 run 요약 줄로 확인한다.
- 녹음 길이를 못 읽으면(드문 형식) 1시간으로 가정해 보여 준다.

## 4. 이 PC 에서 바꾸기 (`local-gpu` · `local-cpu`)
1. **설치 동의(처음 한 번)** — check 가 알려 준 설치 명령·크기를 그대로 보이고 묻는다: *"음성 인식 프로그램 faster-whisper 를 설치하고(약 100MB) 첫 변환 때 모델을 내려받습니다(가벼운 모델 약 0.5GB, 정확한 모델 약 1.6GB). 녹음은 이 PC 안에서만 처리되고 밖으로 나가지 않습니다. 진행할까요?"* → 동의하면 설치 명령 실행(ffmpeg·그래픽카드는 없어도 된다 — 오디오는 PyAV 가 읽는다).
   - 그래픽카드(`local-gpu`)는 NVIDIA 라이브러리가 추가로 필요하다: `nvidia-cublas-cu12`, `nvidia-cudnn-cu12==9.*` (약 1GB 이상). check 가 명령에 포함해 준다. 안 되면 run 이 CPU 로 자동 전환한다.
2. **변환** — `python scripts/transcribe.py run <녹음 파일> --hint "<과제명> <전문 용어> <참석자 이름>"` 를 **백그라운드로** 돌린다(긴 회의는 수십 분 — 셸 제한 시간에 걸리지 않게). 30초마다 `진행 N% …` 줄이 찍힌다. 사용자에게는 "변환 중입니다, 끝나면 알려 드립니다" 한 줄.
   - `--hint` 는 인식기가 과제명·용어·이름을 더 잘 알아듣게 하는 힌트다(과제명·장비명·물질명·참석자 이름을 띄어쓰기로).
   - 모델: 그래픽카드면 정확한 모델 turbo, CPU 면 가벼운 모델 small 이 기본. 정확도가 부족하면 `--model turbo`(CPU 는 느려진다).
   - 원본 녹음은 옮기거나 지우지 않는다. 결과는 `{kiki_root}\meeting\transcripts\<녹음 이름>_녹취록.txt`(`[분:초] 문장` 줄, 덮어쓰지 않음).
3. **결과 점검** — 마지막 줄 `[요약] 녹음 N분 → 글 N자(말한 구간 N분, N문장, 지어낸 문구 N개 뺌), 모델·장치, N분 걸림 → <파일>`.
   - `⚠ 말한 분량에 비해 글이 너무 적습니다` → 한국어 회의가 맞는지·녹음 소리가 작은지 확인하고, 정확한 모델로 한 번 더 또는 6절.
   - `⚠ 그래픽카드 준비 실패 … CPU 로 다시` 는 자동 복구된 것 — 요약 줄만 보면 된다.
   - `ERR 모델 … 내려받지 못했습니다` → 인터넷·사내망 프록시·VPN 확인 후 1회, 안 되면 6절.
   - `ERR faster-whisper 가 없습니다`(종료 코드 2) → 설치 동의 단계부터.
4. 녹취록을 읽고 5절대로 초안.

## 5. 기록(글·녹취록) → 회의 제목·회의내용 초안
- **기록에 있는 내용만** 쓴다 — 기록에 없는 성과·수치·결정을 지어내지 않는다. 자동 변환 녹취록은 사람 이름·과제명·용어가 틀릴 수 있으니, 확실하지 않은 말은 초안에서 표시해 확인받는다.
- **회의 제목** = 주된 안건 한 줄. 과거 회의 제목과 같거나 비슷하면(중복 방지 스캔, SKILL "중복 방지") 알리고 다른 표현을 제안한다.
- **회의내용**(10만원 이상) = 논의 사항·결정 사항·후속 조치를 `1.` `2.` 항목으로, 항목 사이 빈 줄, 항목당 하위 불릿 4개 정도, **괄호 금지**(`meeting_form.md` 회의내용 절). 10만원 미만은 목적 한 줄.
- 초안을 **보여 주고 승인받은 뒤** 회의록 팝업에 입력한다(사용자가 고치라는 곳만 고친다).
- 참석자는 녹취록에서 추정하지 않는다 — 목소리로 사람을 구분하는 기능은 무겁고 부정확하고, 내부·외부 참석자는 참여연구원 여부로 서버가 판정한다. 명단은 SKILL 단계 7 대로 묻는다(클로바노트의 화자 이름은 참고만).

## 6. 휴대폰·클로바노트로 글 받기 (`phone`)
사용자에게 아래를 그대로 안내하고, 받은 텍스트 파일로 2절부터 한다.
- **휴대폰 녹음 앱의 텍스트 변환**: 갤럭시 기본 음성 녹음 앱 등 최신 휴대폰 녹음 앱에는 녹음을 글로 바꾸는 기능이 있다(기종·버전에 따라 없을 수 있다). 변환한 글을 텍스트 파일로 내보내거나 복사해서 주시면 된다.
- **클로바노트** https://clovanote.naver.com — 네이버 계정으로 웹·앱에서 녹음 파일을 올리면 말한 사람별로 글로 바꿔 준다. 결과를 텍스트로 내려받아 주시면 된다. ⚠ 녹음이 네이버 서버로 올라가므로 **내부 회의는 기관 보안 기준을 먼저 확인**하도록 한 줄 덧붙인다.
- **온라인 회의**: Teams·Zoom 등으로 한 회의는 회의 도구가 만든 녹취록·자막 파일(docx·vtt)을 그대로 주시면 된다.
- 사용자가 "그래도 이 PC 에서 하겠다" 고 하면 check 의 대안(`local-cpu`)으로 4절.

## 7. 회의시간 힌트 (SKILL 단계 8)
check 의 `[녹음]` 줄: `녹음 시작 YYYY-MM-DD HH:MM(파일 정보)` 또는 `파일 이름 시각 …` + 길이. 녹음 시작 시각과 길이로 회의시간을 제안한다(예: 13:02 시작·62분 → 13:00~14:05). 카드 승인 시각으로 짐작하는 것보다 우선하되 사용자 확인. `파일 수정` 시각은 복사할 때 바뀔 수 있어 참고만.

## 8. 보관·보안
- 녹취록·회의기록 텍스트는 `{kiki_root}\meeting\transcripts\` 에만 둔다(로컬). repo·외부 서비스·메일로 보내지 않는다. 회의록 엑셀에는 요약만 남는다.
- 모델 파일은 `{kiki_root}\_models\whisper\`(지워도 다음 변환 때 다시 받는다). 패키지를 지우려면 `python -m pip uninstall faster-whisper`.
- 원본 녹음 파일은 사용자 것 — 옮기거나 지우지 않는다.
