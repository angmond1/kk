## 파일명/위치 표준 (2026-09-24 개정)
- 위치: `{kiki_root}\meeting\meeting_log\` **한 폴더**(연월 하위폴더 없음, 기본 `C:\kiki\meeting\meeting_log\`).
- 파일명: **`{yymm}_회의록.xlsx`** (yymm = **지급신청 처리 연월**, 예 `2609_회의록.xlsx`) — 그 달 처리 건은 모두 이 파일에 행 추가. 상신을 나눠도 파일은 월 단위 1개.
- hwpx 를 요청받은 경우 **같은 폴더**에 `{yymmdd}_{과제번호}_{과제이름 아주 간략히}_회의록.hwpx` (hwpx 는 1건씩).
- **주된 목적 = 중복 방지 기록** — 새 회의록을 쓰기 전 이 폴더의 모든 `*_회의록.xlsx` 를 `all_titles()` 로 스캔해 주제·내용이 과거와 겹치지 않게 한다.

## 9컬럼 형식
| # | 컬럼 | 내용 | 예시 |
|---|------|------|------|
| 1 | 순번 | 1, 2, ... | 1 |
| 2 | 사용일자 | 회의 일자 + 시간 (또는 카드 결제일자) | `4월 30일 13:00~14:30` |
| 3 | 금액 | 원, 정수 (콤마 포맷) | `323000` |
| 4 | 장소(거래처) | 식당명 = 카드 거래처 | `○○식당` |
| 5 | 처리계정 | 7자리 계정코드 | `2E11111` |
| 6 | 내부참석자 | 성명, 쉼표 구분 | `김키키` |
| 7 | 외부참석자 | 성명, 쉼표 구분 | `이키키, 박키키, ...` |
| 8 | 외부참석자 소속 | 줄바꿈으로 다소속 구분 | `○○대학교` (또는 `A University\nB University`) |
| 9 | 회의목적 | 제목 + 줄바꿈 + 상세 내용 (10만원↑) | `연구 진행상황 논의\n1. ...\n2. ...` |

⚠️ 회의목적 셀에 **목적(제목) + 상세 회의내용**을 함께. 줄바꿈은 `\n` (셀 내 wrap_text).

## 사용일자 표기
- 같은 날 식당+카페 = 1건 → 사용일자에 식당의 식사 시간 기준 (또는 결제 시간 기준).
- 외화결제(해외) = 한국시간/현지시간 함께. 예: `2월 5일\n(미국시간 2월 4일 11시)`.

## 회의시간 융통성 (사용자 확정)
- **회의 종료시간 = 카드승인시간(USETIME)을 참고해 융통성 있게 설정**. 결제는 회의 직후 → 종료 ≤ 결제.
- 예: USETIME 14:38 → 회의 13:00~**14:30** (결제 직전 정각/반정각).
- 30분/시간 단위 반올림 자연스럽게.

## 회의내용 작성 (10만원↑)
- **작성 주체를 먼저 묻는다** — 사용자가 직접 적으면 그대로 기록, "작성해 달라"고 할 때만 Claude 가 근거자료(제안서·보고서)로 작성. 임의로 채우지 않는다.
- **10만원 미만 = 회의내용 생략 가능 (목적 1줄)** / **10만원↑ = 상세 작성**.
- 무작위 금지 — 회의목적 + 해당 과제보고서 테마 참고. 항목당 4 하위불릿 정도, **1.·2. 항목 사이 빈 줄 1개**.
- ⭐ **중복 금지**: 과거 엑셀(`meeting_log\*_회의록.xlsx`, `all_titles()`) 스캔 → 제목·내용 모두 이전과 다르게.

## 한글파일(hwpx) — 사용자가 요청할 때만
설치 때 묻지 않는다. 옛 설정 `log_format` 은 무시한다(2026-09-24 사용자 지시).
- ⚠️ 2026-09-24~ 이 설정으로 hwpx 를 **자동 생성하지 않는다**(값과 무관하게 엑셀만 자동, hwpx 는 매번 물어봄). 키는 호환용으로만 남김.
- `xlsx_only`: 엑셀만 (기본).
- `xlsx_and_hwpx`: (구) 엑셀 + 별지1호 hwpx 도 **같은 `meeting_log\` 폴더**에 생성(`{yymmdd}_{과제번호}_{과제이름 간략}_회의록.hwpx`). **Claude 는 그래도 엑셀만 조회**.

⚠️ **사전결재 < 회의록 우선** — 엑셀에 적힌 내용이 진짜 결과물, 사전결재는 회의 전 계획. fam_0704 사전결재 연동 시 회의내용이 사전결재 템플릿으로 덮어써지면 → 엑셀 원본으로 복원 (자세히는 `fam_0704_automation.md` §9-e).
