# 자산 / 비자산 판정 (보수적)

## ⛔ 판정 철학 — 가장 우선
**소액검수는 대부분 비자산이다.** 보수적으로 판정한다 — 웬만하면 비자산으로 **자동 진행**하고, 자산으로 볼 근거가 뚜렷할 때만 **"이건 자산 같은데 맞나요?"** 라고 사용자에게 확인한다. **비자산은 묻지 않는다.** 애매하면 비자산 쪽으로 기운 뒤, 자산 가능성이 있으면 그때만 확인한다.

## 판정 기준 (wiki 「7-1 자산의 등록」)
**자산(비유동자산)** = 통상 1년 이상 사용 + 아래:
- **기계장치 / 공기구비품**: 취득가 **100만원 이상**
- **PC·노트북 등 정보관리 물품(완제품)**: **50만원 이상** — 저장장치(SSD·HDD)는 **쓰임새로** 가른다: NAS 등 IP 스토리지용 50만↑ = 자산, PC 부품용 = 비자산 (아래 판정 순서 3)
- **컴퓨터 소프트웨어**: **1천만원 이상** (이 미만 SW는 비자산)
- **GPU(그래픽 처리장치)**: 취득단가 **100만원 이상**이면 **자산** — PC 에 끼우는 부품(GPU 단품)이어도 자산(저장장치와 다름). GPU 관리기준 변경(공지 2026-05-19, 근거 본부장회의 2026-02-26), 정본 `../../_shared/rule_changes.md` `gpu_asset`
- 시설자산(건물·구축물), 기타(차량운반구·도서)

**비자산(소모품/재료/기타)**:
- 1년 미만 사용 시약·소모성 부품·재료
- 자산성 미달 SW (1천만 미만)
- 전극·셀·글래스·시약·소모품 등 연구 소모재

**내용연수**(자산 등록 시 참고): 기계장치 8년 / 공기구비품 5~8년·노트북 6년 / 컴퓨터SW 3년 / **GPU 3년** / 차량 5년

## 판정 순서 (품목별)
1. **SW/클라우드/라이선스** → 1천만↑ 자산 · 미만 비자산
2. **GPU(그래픽카드·GPU 서버·GPU 가 든 PC)** → 취득단가 100만↑ **자산**(묻지 않고 자산으로, 결과 표에 '자산 — GPU 관리기준' 한 줄) · 100만 미만 비자산(재료비)
   - 구매물품분류 `0062 그래픽처리장치`(GPU 단품·GPU 서버 모두), 과제(지급계정) 필수, 내용연수 3년.
   - 금액은 **1개 단가**로 본다(100만 미만 GPU 여러 개를 합쳐 100만↑ 이어도 각각 비자산). GPU 가 든 완제품 PC·서버는 그 장비 단가로.
   - 증빙의 비목이 **연구재료비(15-330 등)** 면 멈추고 알린다: '100만원 이상 GPU 는 연구시설·장비비로만 살 수 있습니다(재료비는 정산 불인정). 실행예산변경으로 장비비를 먼저 잡아야 합니다.' — 검수 입력은 사용자 확인 뒤.
3. **PC·노트북·정보관리기기** → 50만↑ 자산(확인) · 미만 비자산
   - **⚠️ 저장장치(SSD·HDD)는 쓰임새로 가른다 (2026-10-12 사용자 확정)**: **NAS 등 IP 스토리지**에 쓰면 50만↑ **자산**(과제 지정, `radio2='Y'`) / **컴퓨터 부품**(PC 에 넣는 SSD·HDD — 메인보드·파워·쿨러·케이스와 함께 조립)이면 **비자산**으로 검수(50만 기준 미적용, 일반 물품처럼 100만↑ 소액검수) — 이 경우는 묻지 않는다. 제품 종류(NAS 용 드라이브 등)가 아니라 실제 쓰임새로 판단하고, 증빙으로 안 보이면(저장장치만 따로 산 건 등) "NAS 용인가요, PC 부품인가요?" 한 번 묻는다. PC 조립용 부품(메인보드·파워·쿨러·케이스)도 비자산 — **단 GPU 는 부품이어도 100만↑ 자산(순서 2)**. 정본 `../../_shared/rule_changes.md` '헷갈리기 쉬운 현행 값'.
4. **일반 물품** → 100만↑ 그리고 1년↑ 비소모성·독립기능 → 자산(확인) · 아니면 비자산
5. **소모성**(시약·전극·부품·재료·글래스류) → 비자산
6. **시작품/시제품** → 별도(수탁사업운영팀) — 사용자 확인
7. **회색지대**(완성PC·노트북 등 50만↑ 정보기기 완제품·쓰임새가 안 보이는 50만↑ 저장장치·한 거래에 자산+비자산 혼재) → 단정 X, 근거 제시하고 사용자 확인

## 검수창 반영
- 비자산 → `radio2='N'`, `ds_main_NOT_ASST_INFO`, 과제(지급계정) 생략.
- 자산 → `radio2='Y'`, `ds_main_ASST_INFO`, **과제(지급계정) 필수** + 도입방법·구매물품분류·자산표준분류·사용자·사용책임자 등 추가 입력. (`mcs0003_fields.md`)

## 검수 담당·기준 보강 (wiki 구매·자산팀 「3.외자물품구매」 2026-08-14 개정)
- **검수(300만원 이상, 구매요구 검수)** 와 **소액검수(100만원 이상~300만원 미만)** 담당은 구매·자산팀 검수 담당자(원문 담당자 정보 참조). 저장장치가 포함된 정보화기기 **자산**은 검수 기준 **50만원**(위키 원문) — 저장장치는 쓰임새로 가른다(판정 순서 3: NAS 등 IP 스토리지용 = 자산, PC 부품용 = 비자산).
- 구매요구(300만원 초과·외자 미화 3천불 초과) 접수 후 **자체조달 최소 45일(종전 30일)·중앙조달 90일** 소요, 1천만원 이상은 연구계획서 첨부.
- 구매·자산팀 wiki 개편(2026-07-15): (양식)내자구매·외자구매·용역계약 / (참고)구매자산팀 관련규정 페이지 신설 — 양식은 그쪽에서.
