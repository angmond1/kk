# 회의비 비목·사전 내부결재 필요 여부·참석자·발의자 (kk-meet)

> 과제번호 구조·분류코드 의미(N/E/I/S/B/F/K/G…)는 **`../../_shared/project_codes.md`** 참조. 여기는 **회의비 고유 규칙**만.
> ⭐ 현행 규정(근거·집행 가능 사례표·사전 내부결재가 남은 경우의 요령)은 **`meeting_form.md` 「사전 내부결재·참석자 — 현행」** 이 기준이다. 이 문서는 과제 코드로 판정하는 법만 적는다.

## 사전 내부결재 필요 여부 — 현행 (2026-08-01 사용분부터, 영수증 기준)
근거: 재무팀 공지 「국가연구개발사업 회의비 집행기준 완화 안내」(2026-08-04) · 재무팀 위키 「2. 지급신청 매뉴얼」(2026-09-15).
- **기본 = 필요 없음(폐지)** — 폐지 대상: 과학기술정보통신부·산업통상자원부·문화체육관광부·식품의약품안전처·국방부·환경부·보건복지부·경찰청·기상청 과제 + 주요사업과제. 분류코드 **`I`·`S`·`B`·`F`·부서운영비(부서계정)** 는 원래 면제.
- **확인 필요(아직 남을 수 있음)** — 위 목록에 없는 부처의 과제(소관부처 규정이 바뀌면 단계적으로 폐지), 자체·석좌 `K`(국가R&D 공지 대상이 아님). 통합정보 회의비 화면이 과제별로 사전결재 첨부 여부를 확인하므로(공지상 2026-08-01 적용) 그 표시를 따르고, 애매하면 수탁사업운영팀 부처 담당에게 확인. **이때만** `fam_0100` 조회·연동.
- **과제와 무관하게 남은 것** — 휴일 사용·출장이 아닌 근무지 밖 사용 = 차상위자 전결 사전 내부결재(비정산 과제 포함, 매뉴얼 2026-09-15).
- **코드로 판정**(설치 때 '필요 없음' / '확인 필요' 두 갈래로만 보여 준다. 분류코드 = 과제번호 숫자 다음 첫 영문자, `M` 은 둘째 글자로 부처 구분 — 재무팀 매뉴얼 분류):

  | 과제 | 판정 |
  |---|---|
  | `E`(주요사업) · `N`·`U`(과기정통부) · `MR`(산업부) · `ME`(복지부) | 필요 없음 |
  | `I`·`S`·`B`·`F`·부서운영비 | 필요 없음(원래 면제) |
  | `M`(기타 부처 국가R&D) · `G`(공공수탁) · `V`·`Z`(주요사업 외 기관고유) | 소관부처(또는 주요사업 여부)를 한 번 확인 — 폐지 대상이면 필요 없음, 아니면 확인 필요 |
  | `K`(자체·석좌) | 확인 필요 |

- 옛 기준(2026-07-31 이전 사용분 — 지금 쓰지 않는다): I·S·B·F·부서운영비만 면제, 그 밖의 정산과제와 K 는 외부 인원 참석 회의에 사전 내부결재 필요. (그보다 옛 `I·S·K` 면제는 부정확.)

## ⭐ 참석자 — 과제 미참여자 기준 (2026-08-01 사용분부터, 실증 2026-08-07)
- **모든 정산과제는 과제 미참여자 1명 이상 참석 필수**(재무팀 공지 「국가연구개발사업 회의비 집행기준 완화 안내」(2026-08-04)). 집행 가능 사례표 → `meeting_form.md`.
- **내부란 = 그 계정의 참여연구원만** 등록 가능. KIST 소속이어도 참여연구원이 아니면 거부된다(`본 계정의 참여연구원이 아닙니다. 내부인원은 참여연구원만 등록 가능합니다.`).
- **외부란 = KIST 소속 미참여자 + 외부기관 소속 전원**. KIST 미참여자는 회사명 **`한국과학기술연구원`**. 사람마다 **`PROJJOINYN`**(참여연구원 여부) 필수 — `N`=미참여 / `Y`=참여(외부참여연구원). 미지정 시 저장 거부. **외부란이 전부 Y 면 미참여자가 없어 집행 불가**.
- 참여연구원 명단을 미리 조회하는 API 는 없다(`ds_parti_chk` 는 건별 확인용 요청 데이터셋) → **한 명씩 내부로 등록 시도해 서버 판정**에 맡긴다.
- 총원(내부+외부)은 인원 하한(⌈금액÷5만⌉) 이상. 사전결재를 연동하는 경우(남은 경우)만 그 결재 인원과도 맞춘다(내부→외부로 옮겨도 총원 불변).
- 화면 조작 상세 = `fam_0704_automation.md` §9-c.
- 옛 기준(2026-07-31 이전 사용분 — 지금 쓰지 않는다): 내부 = KIST 소속, 외부 = 타 기관 소속, 정부수탁은 외부기관 인원이 있어야 식비 가능 + 사전 내부결재.

## 발의자 vs 계정책임자 (fam_0100 검색 기준 — 사전 내부결재가 남은 경우만)
- **일반 사용자 = 발의자(본인)** 기준 검색(`KORNM`=본인 이름, `PAYNO`=본인 사번 = kiki.config.json `user`).

## 런타임 분기 — 회의 제목·내용은 어디서 오나
- **기본(2026-08-01 이후 사용분 — 사전결재 없음)**: 회의 기록(글·녹음)을 먼저 받고, 없으면 주제를 묻는다(SKILL 단계 5). 회의내용은 기록 또는 사용자 글로, 작성을 부탁받은 경우에만 `project_report\` 의 제안서·보고서로 초안(과거 회의록과 중복 금지). 장소 = 실제 회의장소(보통 카드 거래처).
- **사전 내부결재가 남은 경우·2026-07-31 이전 사용분**: `queryPreApprovals`→`matchPreApproval` 로 매칭 → 목적·장소·시간을 가져오고 fam_0704 회의록 팝업 `button00_onclick` 으로 연동(`fam_0704_automation.md` §9-d). 매칭되는 결재가 없으면 기본 흐름으로.
- ⚠️ **사전결재 < 회의록 우선** — 연동 시 회의내용이 덮어써지면 엑셀 원본으로 복원(§9-e). 일시·장소·인원·계정이 다르면 변경사유만 기재.
