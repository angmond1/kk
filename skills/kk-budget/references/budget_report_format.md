# kk-budget — 리포트 양식·집계 규칙

> 예산 수집 결과를 (1) 세션 채팅 표 (2) 엑셀 파일로 내는 표준 양식. 사용자가 형식을 바꾸면 config/대화로 조정.

## 추적 카테고리 (기본 6, config `track_categories`)
재료비(15) · 시설장비비(11) · 활동비1(33) · 활동비2(34) · 내부인건비2(05) · 학생인건비(31).
- 사용자가 가감 가능. 간접비·내부인건비1·연구수당·위탁연구개발비 등도 BUDGITEMCD로 추가 가능(`budget_fetch_spec.md` 코드표).

## 직접비 소계 (우측 고정 열)
- `직접비` = getMainList 응답에서 **`BUDGITEMCLSNM=='직접비'` & `LEV=='1'` & BUDGITEMCD 있는** 카테고리들의 A·D 합산 (= 화면 "소계 [직접비]"와 일치, 실증 검증됨).
- 추적 6개만의 합이 아니라 **직접비 분류 전체**(내부인건비1·위탁연구개발비·연구수당 포함).

## (1) 세션 채팅 표 — 항상 출력
- 행 = 과제(`과제번호 (PI·역할)`), 열 = 카테고리.
- **각 카테고리 셀 = 잔액만**(총액 표시 안 함).
- **맨 우측 열 = 직접비 (잔액/총액)**.
- 단위 백만원(소수 1자리) 약식, `–` = 해당 과제에 그 카테고리 없음.
```
| 과제 (PI·역할) | 재료비 | 시설·장비 | 활동비1 | 활동비2 | 내부인건비2 | 학생인건비 | 직접비 (잔액/총액) |
| 2X11111 (김키키·주관) | 12.3 | 4.5 | 20.0 | 8.0 | 1.0 | 0 | 200.0 / 500.0 |
```

## (2) 엑셀 (`make_report.py`)
- 행 = 과제, 열 = 과제번호·과제명·PI/역할 + 카테고리별 **총액/잔액 2칸** + **(한 칸 띄우고) 직접비 잔액/총액**.
- 직접비 순서는 **잔액 먼저, 총액**(채팅과 동일). 카테고리는 총액/잔액.
- 학생인건비(마지막 카테고리)와 직접비 사이 **구분 빈 열 1칸**(폭 좁게).
- 총액=회색(muted), 잔액=검정 bold. 헤더 진파랑, 잔액 서브헤더 살구색.
- 단위 원(`#,##0`). 출력 파일명 `yymmdd.xlsx`, 폴더 config `output_dir`(기본 `C:\kiki\budget`).

## make_report 입력 JSON (`scripts/make_report.py <input.json> <out.xlsx>`)
```json
{"snapshot_date": "YYYY-MM-DD",
 "track_categories": ["재료비", "시설장비비", "활동비1", "활동비2", "내부인건비2", "학생인건비"],
 "projects": [{"acccd": "2E11111", "name": "○○ 연구", "pi": "김키키", "role": "주관",
               "direct": {"A": 0, "D": 0},
               "categories": {"재료비": {"A": 0, "exec": 0, "pendingDone": 0, "pendingProg": 0, "D": 0}}}]}
```
- `projects` 는 위처럼 목록이어도, `{"2E11111": {...}}` 사전이어도 된다. 카테고리 이름은 `portal_ops.js` `CAT_MAP` 의 표시명과 **글자 그대로** 같아야 하고, 과제에 없는 비목은 키를 빼야 `-` 로 찍힌다.
- 값은 `kkBudget.queryBudgetTable()` 반환을 그대로 넣으면 된다(A=총액, D=잔액; exec·pendingDone·pendingProg 는 검산용).

## 검산 (수집 시 자동)
`LASTBUDGAMT(A) = BALNAMT(D) + CTRLPERFAMT(집행B) + CTRLCAUSAMT(계류완료) + TEMPAMT(계류진행)` — 불일치 시 경고.

## 개인집계 (optional, config `personal_share`)
- 공동과제에서 **본인 사용분만** = 집행내역 적요에 config `filter_names`(연구자명/행정원명/혼합) 중 하나 포함 건 합산(완료+계류).
- `merge_act2_into_act1=true`면 활동비2 사용분을 활동비1 풀에 합산.
- 할당 기준액(config `allocations`)−사용분 = 본인 잔액.

## 과책(PI) 권한 — 참여과제
- 본인이 PI가 아닌 과제(`pi != 본인`)는 과제 *전체* 카테고리 A/D는 fetch로 오지만, **개인집계용 집행내역(적요)·내부인건비2·학생인건비 상세는 권한 제한** 가능 → 그 경우 "총액만(과책 권한)" 표기.

## money 표기
- 채팅: 백만원 약식(소수 1자리). 엑셀: 원 단위 `#,##0`.
