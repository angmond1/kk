# dooray 행정원 폴더 조회

> `scripts/dooray_drive.py` 의 근거. 업로드 대상 = 담당 연구행정원의 RPA 폴더.

## 공통 (전사 동일, 개인정보 아님 — 내장 OK)
- projectId `3311002956353796322` / driveId `3311002957555545393` = `RPA-지급신청자동화` (전 본부·행정원 공유 1개 프로젝트).
- 폴더 웹주소: `https://kist.gov-dooray.com/drive/3311002956353796322/{folderId}`

## 폴더 지정 2-옵션
- **옵션1 (권장)**: 행정원이 공지한 폴더 **링크 붙여넣기** → URL 끝 `{folderId}` 추출. 100% 정확·즉시.
- **옵션2 (보조)**: 행정원 **이름 검색**(`find_admin_folder`). 본부명(약어 가능) 주면 root 목록을 한 번 읽은 뒤(2~3분) 그 본부 안만 훑고, 모르면 전수(최대 5분). Bash 로 부를 땐 `timeout: 600000`.

## ⚠️ 이름 검색 한계 (실측)
- 동명 폴더 **복수** + 구조 **제각각**(행정원에 따라: 본부 아래 정식폴더 + root 비정식이 공존하거나, root 에 빈·옛 폴더만 있는 등).
- **정식 RPA 폴더 식별** = 하위에 `1.세금계산서`·`2.회의비`·`▶지급신청 매뉴얼` 보유(`isRPA=true`). 복수·모호 시 웹주소·경로 보여주고 사용자 1개 선택.

## 폴더 구조 → 업로드 위치 (`folder_structure`)
- `card` = 행정원 폴더 root 직접(카드 건)
- `taxInvoice` = `1.세금계산서` 하위(있으면) / `meeting` = `2.회의비` 하위(있으면)
- `hasSeparate`=true → "세금계산서·회의비도 각 폴더로 따로 올릴까?" 분기. false → "카드·세금계산서·회의비 중 어디까지?" 분기.

## 성능 + 캐시 (실측)
- root 에 약 **8,656 항목** → 이름검색(전수)은 root 페이징만 87 calls ~3.5분. **옵션1 압도적**.
- 옵션2 는 root 목록을 한 번만 읽어 재사용한다(본부 캐시는 없음). 찾은 폴더 링크를 kiki.config `payment_admin.folder_url` 에 저장해 두면 다음부턴 검색이 필요 없다.
- ⏳ 이름검색은 **"검색 중…"** 진행표시 + **"최대 5분"** 안내(다운 오해 방지). `find_admin_folder(progress=...)`.

## 인증
- 폴더 조회·업로드는 **dooray 개인 토큰** 필요(`<kiki_root>/token.txt`, 구형 `~/.claude/kiki/kiki.env` 도 읽힘). 발급 `https://kist.gov-dooray.com/setting/api/token`.
