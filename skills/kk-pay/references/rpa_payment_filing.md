## 0. 개요 / 공통
- RPA(Robotic Process Automation)가 **지급신청 담당자 대신** 지급신청 수행. 두레이에 정보(증빙 파일) 제공 → RPA가 통합정보에 기안·상신.
- 공통 동작:
  - 결재선상 직원이 **직무취급/겸직**이면 RPA는 통합에서 검색되는 **첫 번째 직책** 선택.
  - **계정책임자가 복수**면 RPA는 통합에서 검색되는 **첫 번째 계정책임자**만 결재선에 추가.
- RPA 종류 3가지: ① **카드/세금계산서**(§1~4, kk-pay 본업) ② 전화료(§5) ③ 전문가활용(§6). ②③은 별도 입력경로.

# 라. 법인/연구비카드·세금계산서 RPA (★ kk-pay 본업)

## 1. RPA 대상 / 비대상  (⚠️ 기존 오해 정정)
- ✅ **대상**: **재료비 등 일반 지급신청 일체** — **법인카드·연구비카드·세금계산서 전부 포함**.
- ❌ **비대상**(RPA 안 됨 → 기존 방식/직접): **회의비 · 전문가활용 · 전화료 · 전기료 · 도서비 · 용역 · 공사**.
  - (전화료·전문가활용은 각자 별도 RPA 경로 §5·§6이 있고, 회의비는 kk-meet/수기.)
- 💡 **세금계산서도 RPA 대상**이다(과거 "세금계산서는 행정원 수기"는 오해). RPA가 OCR로 국세청승인번호·통장사본을 읽어 처리 → **fam_0702 직접작성에서 막히는 계좌 실명검증을 RPA가 OCR/자주사용계좌로 대신 처리**(§3 계좌).

## 2. 증빙 업로드
- 증빙(거래명세서 등)을 **'RPA-지급신청자동화' 드라이브 내 소/본부별 담당자 폴더**(`001234_김키키` = 개인번호_지급신청자이름)에 업로드.
- 드라이브 대표링크: `https://kist.gov-dooray.com/drive/3311002956353796322/3311048581150223585` (웹 주소는 projectId, API 는 driveId — `../../_shared/dooray_wapi.md`)
- 멤버 아니어도 업로드 가능. 드래그&드랍.
- 통합 영수증함 **반영 전 지출 건도** 두레이에 증빙 업로드 가능.
- 연구자↔행정원 소통은 **파일명**으로(예: 파일명 `2N11111 계정으로 지급신청 부탁` / `추가 증빙 있으니 대기`).

## 3. 증빙 파일명 규칙 (실패 1순위 원인)
언더바(`_`) 구분, **80자 이내**.

**법인/연구비 카드**:
```
(계정번호)_(항목코드)_(비목코드)_(카드승인번호)_(적요)
```
- 카드승인번호 = fam_0711 `CARDAPPRNO`. 외화도 임의환산 말고 원화청구액 `USEAMT` 그대로.

**세금계산서**:
```
적요 작성:   (계정번호)_(항목코드)_(비목코드)_(국세청승인번호 24자리)_(적요)
적요 미작성: (계정번호)_(항목코드)_(비목코드)_(국세청승인번호 24자리)_0
```
- **국세청승인번호 생략 가능**: '세금계산서 증빙'을 첨부하면 RPA가 **OCR로 국세청승인번호를 읽어 영수증함 선택**(세금계산서가 증빙 첫 번째일 필요 없음).
- **적요 미작성(`…_0`)** 시 세금계산서상 **품목/공급일자로 적요 자동 표기**.

**통장사본**: 파일명에 **`_통장사본`** 명시해야 OCR 인식. 예) `2G11111_15_321_김키키] 4000 Series M_통장사본`

**복수 증빙**(2개 이상): **동일 파일명 + 끝번호 `(1) (2) (3)`**. 예) `2E11111_15_330_12345678_김키키]○○ 시약 외 6건 구입 (1)` / `… (2)`

## 3-계좌. RPA 계좌 입력 방법 (★ 직접작성의 계좌검증 우회)
- 1순위: **통장사본 OCR** 리딩하여 계좌 입력(파일명 `_통장사본` 필수).
- 2순위(통장사본 없을 때): **자주사용계좌 자동입력** — 전 연구행정원이 등록한 계좌 중 **사업자등록번호 기준 최신 등록 계좌**.
- ⚠️ **'자주사용계좌조회'로 조회 안 되는 업체는 통장사본 업로드 필수.**

## 4. RPA 수행 / 결재선 / 결과 확인
- **수행시간**: 매일 **오전 10시 / 오후 3시 / 오후 10시** (1건당 약 4분).
- **결재선**: RPA기안 **지급신청자(두레이폴더 담당자)** → **계정책임자 전결**. (지급신청자가 결재선 추가·변경 가능)
- **기록물철**: 연구책임자 소속부서 지급신청 계정의 **'예산관리' 폴더**.
- **결과 확인**: ✅ 성공 = **두레이 폴더의 해당 첨부파일이 삭제됨** / ❌ 실패 = **파일이 그대로 남음** + 결과 이메일 안내.
- **오류 시 재상신**: 지급신청자가 지급신청서 **반려 후 통합에서 삭제** → ⓐ 두레이폴더 서류 보완(자동 재상신) 또는 ⓑ 수기 지급신청.
- **실패 사례**: ① 파일명 규칙 미준수(언더바 구분·계정/승인번호 등 기초정보 오류) ② 계정잔액/신청가능금액 부족(잔액<신청금액 또는 0원) ③ **검수 미완료**.

# 나. 전화료 RPA (별도 경로 — 엑셀 입력)
- 'RPA-전화료-실무' 두레이 드라이브의 **월별 전화료 엑셀**에 부서별 담당자가 계정정보(계정·항목·비용코드·담당자·이메일·부서명·적요) 입력 → RPA가 지급신청.
- Timeline: 매달 **10일** 데이터정보팀 청구액 업로드 → **18일** 담당자 계정 입력(노랑 칸, 복수계정은 행 분할) → 21일 합산확인 → **22일 23시 RPA 일체 지급신청** → 23일 성공/실패 메일(실패 시 수기).
- 결재권 = **계정책임자 전결**. 문서함 = 각 부서 '공통기록물철>행정관리>서무'. 부서명은 통합 공식명칭과 동일해야 함.

# 다. 전문가활용 RPA (별도 경로 — 신고서 기반)
- 대상 = **국내 전문가활용만**(해외는 직접 지급신청). '전문가활용신고서'(경영정보>인사) 의 '전문가활용 계정정보'를 RPA가 활용.
- 결재선 = (1차)신고서 기안자 → (2차/전결)계정책임자. 상신 = 신고서 최종결재(인사경영팀) **다음 날 오전 2시**(활용종료일이 더 늦으면 종료일 다음 날).
- 첨부 = 결재완료 신고서 PDF + 신고서 첨부 전부. 이지바로 과제는 '이지바로 부가정보' 입력 필요.
- 입력값: 사용일자=활용종료일 / 사용구분=이체 / 거래처=주민번호 / 영수증구분 직원=직원·외부인=외부인 / 원천세 직원=근로소득10%·외부=기타소득8%(RPA 안내 2025-11 표기 — 재무팀 지급신청 매뉴얼 2026-09-15 개정본은 **5만원 초과 사례비 지급 시 주민번호·주소 입력 + 소득세 공제 20%** 표기, 원문 확인) / 국내전문가 활용 기준(인사경영팀 2026-08-21 개정): 자격기준 I·II·III 중 **가장 유리한 기준**으로 등급, **1시간 상한액 100만원**(종전 40만원) / 적요=`전문가활용/성명/활용기간/활용목적` / **통장표기 = KIST** / 소득코드=강연료 등.
  - ※ 전문가활용·연구수당의 **통장표기 = "KIST"** (kk-pay 세금계산서 직접작성의 `KIST_` 와 같은 KIST 표준 입금자표기 계열).
