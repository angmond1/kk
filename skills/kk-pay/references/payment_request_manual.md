## ⭐ kk-pay 빠른 참조 (핵심 발췌)

### 물품 검수·자산 (지급신청 전 선행 — 미이행 시 RPA 보류)
- **100만원 이상**: 지급신청 전 구매·자산팀 **모바일 검수** 필수
- **50만원 이상 정보화기기**: 모바일 검수 필수
- **소액물품 건당 300만원 이내** (분할결제 금지) — 초과 시(외자 물품대 미화 3천불 초과) 구매·자산팀 **구매요구 의뢰**(구매요구 접수 후 **자체조달 최소 45일·중앙조달 90일** 소요 — 2026-08 개정, 종전 30일; 1천만원 이상은 연구계획서 첨부)
- 권당 100만원 초과 도서: 연구기획·분석팀 온라인 검수
- 모든 기준 금액은 **부가세 포함** 금액 / **중복집행 불가** / 고가 가구(예: 100만원 초과 의자) 구매 불가

### 주요 반려 사항 (제출 전 점검)
- **계정책임자 누락**
- **관련 부서 협조 누락**: 구매·자산팀(구매요구·용역), 인사경영팀(출장비-항공/비자/PCR 등), 시설운영팀(시설공사)

### 거래명세서 (증빙 핵심)
- 일부 식대 제외 **모든 비용 거래명세서 제출** (카드매출전표에 거래내역 모두 포함 시 전표로 갈음)
- 필수 항목: ①거래일자 ②공급자정보(업체명·주소·사업자번호·대표자·업종업태) ③물품정보(물품명·수량·단가) ④결제정보(온라인 시 할인내역)
- **온라인 거래**: 배송지 정보 포함(주문화면·확인메일). 거래명세서의 '공급받는자 정보'는 배송지로 불인정
- **주문제작(숨고·크몽 등)**: 상세 주문내역 화면 필수(결제화면만으로는 불가)
- **결제대행(KCP·KG이니시스 등)**: 실거래처 확인되는 전표·거래명세서 별도 제출
- **배송지 증빙 생략 가능 업체**: 시그마알드리치, 세진씨아이, 피셔과학, (주)데보라, 태원과학, 한국분석기기, 한국생명공학연구원
- 계약대금(용역/구매요구): 거래처 4대 사회보험료 완납증명서 첨부 / 2200만원 초과: 국세·지방세 납세증명서 추가 (유효기간 확인)
- **해를 넘기는 용역계약**(예 2026/5/20~2027/5/19)은 내부결재·계약의뢰서에 **기획예산팀 협조결재** 필요(연구비 계정은 개발실 계정관리자 협조; 구매·자산팀 「5.용역계약」 2026-07 개정)

### 시험분석비(34-172/173)·장비이용료 (2026-09-15 개정)
- 증빙: 거래명세서 + **시험분석결과서(연구개발서비스 결과서) 첨부 필수**(종전 "해당시·산업부만" → 전 과제 필수) + 카드매출전표 또는 세금계산서(생략가능)
- 결과서 미발행 기관 또는 지급신청 이후 발행 시: **담당자와 해당 비목 집행 가능 여부 확인** + 적요란 기재
- **타 기관 보유 장비를 대여해 쓴 장비이용료**는 **외부기자재임차료 등**으로 집행(시험분석비 아님)

### 회의비 (33-523) — kk-meet 핵심
- **사전 내부결재 폐지 — 2026-08-01 사용분(영수증 기준)부터**: 과기정통부·산업부·문체부·식약처·국방부·환경부·복지부·경찰청·기상청 과제 + 주요사업. 목록 밖 부처 과제는 단계적 폐지(통합정보가 과제별 확인, 수탁사업운영팀). 대신 **모든 정산과제는 과제 미참여자(외부인) 1명 이상 참석 필수** — KIST 직원이라도 과제 미참여자면 외부인, 타 기관 소속 참여연구원(외부참여연구원)은 **내부참석자로 간주**되어 미참여자로 셀 수 없음 (재무팀 공지 「국가연구개발사업 회의비 집행기준 완화 안내」(2026-08-04) · 매뉴얼 2026-09-15; 사례표 kk-meet `meeting_form.md`)
- **1인 5만원** 한도(식대+다과 포함) — 참석인원 조정 금지, 메뉴 최저가 5만원 초과 음식점 불가(예: 63뷔페)
- **50만원 초과**: 일상감사 + 차상위자 결재(상한 소/본부장) — 분할결제 유의
- **휴일/근무지 외 사용**: 차상위자 전결 사전 내부결재(근무지 = 소속 시·군 또는 12km 미만 거리) — 과제별 사전결재 폐지와 **별개로 남은** 규정(비정산 과제 포함, 매뉴얼 2026-09-15)
- **심야(23~6시) 금지**, **주류·유흥 금지**(주점업종 + 일반음식점 등록된 실주점[이자카야 등]도 불가)
- 증빙: 편의점/제과점/마트 = 거래명세서, 백화점 푸드코트/호텔/리조트 = 식당명 기재 영수증, 인터넷 배달 = 배달장소 포함 세부내역. **식당·카페 = 첨부 불요**(카드전표 갈음) — 카페 영수증은 재무팀이 임의로 검사할 수 있으니 **보관**(2026-09-30 사용자 확인, 아래 원문 목록에도 카페 없음)
- 출장 중 사용: 출장식비 공제 여부 확인(미반영 시 식비 반납 + 수입확인서)
- **S·I·F·B·K·G 계정은 17-448 항목**에서 처리 / take-out 커피 등도 회의비

### 회의비 임차료·속기료·세미나개최(33-524)
- 내부결재문서(차상위자, 상한 소/본부장) — 회의일시·장소·참석자·목적·내용·지급계정 기재
- 1천만원 초과 세미나개최 또는 50만원 초과 식대·다과 포함 시 일상감사 결재선 추가
- 회의장 임차료도 300만원 초과 시 구매·자산팀 용역계약

### 연구실운영비 (33-185) — 소액 소모성
- 통상 연구수행 소액(**10만원 이내**) 물품, 적요에 '연구실 운영비' 명시
- 다과 등: 계획서 없이 집행, **10만원 초과 불가**(동일 일자·동일 계정 합산), 산업부 과제 권고 제외
- 정수기 생수: 10만원 초과 가능, 50만원 초과 시 일상감사 + 차상위 결재

### 현금(개인카드)
- **개인카드 지양**. 3만원 미만: 적요에 불가피 사유 작성 / **3만원 이상: 불가피사유서(별첨 양식) + 재무부서장 승인** 후 신청
- **RCMS 과제 연구재료비 현금 집행 불가**

### 원천세 — 지급 유형·거주 구분마다 다르다 (2026-09-15 매뉴얼, Codex 검토 2026-09-30 정정)
⚠ 한 세율로 묶지 않는다. 옛 요약(“사례비 5만원 초과 시 20%, 종전 8%”)은 틀렸다 — 20% 는 **임상실험 피험자 사례비**, 8% 는 **거주자 자문료(인적용역)** 로 둘 다 현행이다.
- **임상실험 피험자 사례비(34-686)**: **5만원 초과** 지급 시 주민등록번호·주소 입력 + 소득세 공제(**외부인/기타소득 20%**) — 종전(재무팀 비교표 '변경 전') "12만 5천원 초과 지급 시 소득세 공제".
- **국내 거주자 자문료·강연료(전문가활용, 인적용역 기타소득, 34-671·17-671)**: 원천세구분 '**외부인/기타소득(8%)**'(매뉴얼 국외 거주자 Q1 예시·RPA 전문가활용 안내 2025-11). 과세최저한 **12만 5천원** 초과 시 원천징수, 이하도 인적용역이라 원천세 정보 입력(재무팀 비교표 자문료 항목). 183일 이상 거주 추정 외국인도 거주자와 같다.
- **국외 거주자(비거주자) 인적용역**: 조세조약 미체결국(대만·홍콩 등)은 '외부인(기타소득) 20%'·원천세거주구분 '국외'. 외국에서 온라인·화상 자문은 국내 원천징수 비대상. 단순 교류로 초청한 비거주자의 항공료·체재비는 사례금으로 22% 대상일 수 있음. 회사가 직접 지급한 항공·숙박·식대는 비과세(거주자가 결제 후 청구하면 과세).
- **직원**: 근로소득(10%). 공통 표: `../../_shared/rule_changes.md` '헷갈리기 쉬운 현행 값'.

<strong><span style="color: rgb(0, 176, 80);">A1.</span></strong> 거주자와 동일하게 원천징수 의무 이행
   ※ 예시 : 자문료 기타소득 지급 시 ‘<strong><span style="color: rgb(255, 0, 0);">원천세구분 : 외부인/기타소득(8%)</span></strong>’ 원천징수

<strong><span style="color: rgb(0, 176, 80);">A4.</span></strong> 국내원천소득에 해당하지 아니함.
