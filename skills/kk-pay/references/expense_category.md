## 1. ⭐ 증빙 파일명 규칙 (실패의 핵심 원인)
```
계정번호_항목코드_비목코드_카드승인번호_카드책임자]내용
```
- 언더바(`_`)로 구분, **80자 이내**, **금지 특수문자** `< > : \ / " | ? *` (`]` `(` `)` 공백은 허용)
- **카드승인번호** = 카드영수증 조회(fam_0711)의 `CARDAPPRNO`. **외화도 임의 환산 말고** 조회 원화청구액(`USEAMT`) 그대로.
- **카드책임자** = 카드 명의자 이름(직책 없이, 예 `…_김키키]…`)
- **복수 증빙** = 동일 파일명 + 끝번호 `(1) (2)`, 각자 확장자
- ⭐ **변경요청서 동봉 규칙 (사용자 지시 2026-09-12)**: 실행예산변경 **O** 비목(33-186 AI 구독 등)은 **영수증 `(1)` + 실행예산 변경요청서 `(2)`** 를 같은 파일명 끝번호로 묶어 올린다 — RPA 가 동일건 첨부로 인식. 예: `2E11111_33_186_12345678_김키키]ChatGPT Pro 구독 (1).pdf` + `… (2).pdf`(=변경요청서 사본). 변경요청서 원본은 여러 건에 재사용하므로 **복사본**으로 붙이고 원본은 폴더에 남긴다. 변경요청서에 없는 항목(예 Google AI Pro)은 사용자 확인 후 영수증만(20만↓ 소액이면 그대로).
- **학회등록비(33-457) 묶음 예**: 등록비 영수증 `(1)` + 카드 매출전표 `(2)` + 학술대회 안내장 `(3)` (예: ○○학회 학술대회). 출장신청서·발표자료가 있으면 `(4)(5)`.
- **같은 달 동일 내용 2건(예 ○○ 구독 8/1·9/1)** 은 승인번호가 달라도 내용부가 같으면 헷갈리니 **`8월 구독`/`9월 구독`** 처럼 월을 넣어 구분.
- **해외 구독 금액**은 영수증(₩NNN,NNN / $NNN)과 카드 청구액(원화 청구액, 해외수수료 포함)이 다르다 — 파일명·금액은 fam_0711 `USEAMT` 기준(§외화 규칙), 영수증은 그대로 첨부.
- **세금계산서 건** = 카드결제 아님 → 승인번호 자리 생략 `계정_항목_비목_카드책임자]내용`
- **카드영수증 + 주문내역(거래명세) 둘 다 있으면 → 주문내역만** 업로드(카드전표는 fam_0711 영수증 이관 처리). 단일이면 끝번호 불요.

## 2. 파일 형식 + 자동 전처리
- **`jpg` · `pdf` 만 가능.** `png`·`jpeg`·`xlsx`·`hwp`·`docx`·`hwpx` 등은 불가 → **자동 변환**(`scripts/convert.py`):
  - 이미지 → `jpg`(Pillow), 문서 → `pdf`(한글/Office COM). 변환 시 사용자에게 "X→Y 변환함" 알림.
  - COM 실패 시 → "직접 pdf/jpg 저장 후 재전달" 안내(멈추지 않음).
- 무작위 숫자 파일명(`1780…png`)은 의미있는 이름으로 개명 후 규칙 적용.

## 4. 집행 한도 (붙임2 시트2)
- 의자 100만 / 책상 300만 초과 집행 불가. 연구실 비치용 슬리퍼 3만 초과 불가.
- 이어폰 10만 / 헤드셋·키보드·마우스 20만 / 태블릿 케이스 10만 / 노트북가방 20만 초과 → 용도설명서(연구비는 실행예산 변경요청서).
- 스마트펜슬·태블릿PC·스마트워치 → 용도설명서. 법인폰 관련 비용·개인성 가방은 전부 불가.
- 회의비 식대(다과 포함) 1인 5만원, 50만 초과 시 일상감사+차상위자, 심야(23~6시)·주류 불가.
- **청탁금지법 합산 한도**(외부인 "공직자등" 대상 — 주요사업 길라잡이 2024-09 p.143~148 — 음식물 5만원은 2024-08-27, 농수산물 선물 15만원(명절 30만원)은 2023-08-30 시행. 위키 본문엔 없고 첨부에만): 식사+선물 총 5만원(농수산물 15만, 설·추석 30만) / 식사+커피 5만원 / 식사+경조사비 총 10만원 / 이어지는 식사(점심·저녁·다음날)는 **합산** / **기념품·선물**은 1인 5만원, 특정 부서 등 **특정군에 여럿이면 특정군 합계 5만원**, 불특정 다수 배포용 홍보품은 적용 제외 / 인·허가·채용·평가 **현안 진행 중 피평가자→평가자 제공은 금액 무관 금지**. 기념품 집행은 비정산(I·S·B)·홍보비·의전비·행사비 계정 + 부서장 내부결재.
- **평가위원 자문료**(외부 평가위원, 길라잡이 2024-09 p.149 — 최신은 기본사업운영팀 확인): 하루 최대 40만원(제세 포함) = 2시간 이하 20만 / 2~4시간 30만 / 4시간 초과 40만. 평가일·주제·대상이 다르면 각각 지급. **식대·다과 제공 불가**(물·음료만), 처리계정 연구기획조정본부 기획평가비, 지급신청 시 기본사업운영팀 협조. 국내 전문가 자문료(A 50 / B 30 / C 20만원)·해외($500/350/250)는 위키 인사경영팀·국제협력팀 페이지가 현행.

## 5. 집행 가능 여부 (붙임2 시트3 핵심)
- 정부수탁/주요사업에서 명함·근무복·통신비·커피머신·기념품·디퓨저·상품권 = 원칙 **불가** (비정산과제 B/S는 일부 가능).
- 다과·생수·커피(회의/비치용) = 연구활동비1(33-185). 단 산업부·복지부 등은 권고 제외.

- 실험복·마스크 = 원칙 불가, 특수목적·직접관련 시 내부결재 후 연구활동비.

## 7. RPA 운영 규칙 (⭐ 상세 [`rpa_payment_filing.md`](rpa_payment_filing.md) — wiki 「7.RPA 지급신청 안내」 정제본)
- **RPA 대상**: 재료비 등 **일반 지급신청 일체 — 법인/연구비카드 + 세금계산서 전부**. (⚠️ 과거 "세금계산서는 행정원 수기"는 오해 — RPA가 OCR로 국세청승인번호·통장사본 읽어 처리.)
- **RPA 비대상**(기존방식/직접): **회의비·전문가활용·전화료·전기료·도서비·용역·공사**. (전화료·전문가활용은 각자 별도 RPA 경로.)
- **RPA 배치**: 매일 10시 / 15시 / 22시 (1건 약 4분).
- **결재선**: RPA기안 **지급신청자(두레이폴더 담당자)** → **계정책임자 전결**. (신청자가 결재선 추가·변경 가능)
- **계좌**: RPA가 통장사본 OCR(파일명 `_통장사본` 명시 필수) 또는 **자주사용계좌**(사업자번호 기준 최신) 자동입력. 자주사용계좌 미조회 업체는 통장사본 첨부 필수. → fam_0702 직접작성의 계좌 실명검증을 RPA가 대신 처리.
- **검수 필수**: 미완료 시 RPA 실패. ⚠️ **물품 100~300만원은 소액검수(mcs_0003) 선행**.
- **결과 확인**: ✅성공=두레이 폴더 파일 삭제 / ❌실패=파일 잔존 + 이메일. 실패사례 = 파일명 규칙 오류·계정잔액 부족(0원 포함)·검수 미완료.
- **실행예산 변경 RPA**(기획예산팀 「3. 실행예산 변경 RPA」, 2026-09 개정): **부서 경상운영비 계정**의 **단일계정 내 비목간** 변경만 대상 — 「(양식) 실행예산변경신청 양식.xlsx」 작성(계정별 파일 분리) → `rpa006@kist.re.kr` 메일(제목 `실행예산변경신청`) → 근무일 **13시·17시** 자동 반영. **순증·감액(0↔xx원)·두 계정 간 변경·매식비(20) 증액은 기획예산팀 별도 문의.** (연구비 과제의 실행예산 변경요청서 동봉 규칙(§1)과는 별개 경로.)
