## 4. 첨부 (패턴 C 변형 — 별도 창 input 옮기기)
- `fileDiv1.extUp._input_node` 가 진짜 `<input type=file multiple>` 인데 **신청서 창의 문서**에 있어 부모 탭에서 `find` 로 안 잡힌다.
- 해법: 그 input 을 부모 탭 `document.body` 로 옮겨(appendChild — 이벤트 연결은 그대로 따라온다) 노출 → `find("kk file upload")` → Claude in Chrome `file_upload(ref, paths)` → 끝나면 원래 자리로 되돌린다(`kkRdp.exposeInput()` / `restoreInput()`).
- Claude in Chrome `file_upload` 는 **로컬 경로를 받는다**(2026-10-20 실측, 한 번 호출에 합계 10MB 미만). 9MB·8MB 연구계획서도 한 개씩 나눠 올리면 된다. 10MB 넘는 파일은 chrome-devtools `upload_file` 로(`../../_shared/nexacro_file_upload.md` §4-6).
- 올린 직후 `ds_files.tmHeader = I`(선택만). 저장(`btn_save`/`btn_approval`) 때 서버로 올라가 `S` 가 된다. `gfn_upload` 를 따로 부르지 않는다.
- 지난 신청(9월)의 첨부: 보안서약서.hwp + 관련과제 연구계획서 2개.
