# 키키 부르기 — 부르는 말 읽기와 요청 → skill 연결 (kk 공용)

사용자는 kk skill 을 이름 대신 **"키키야 …"·"김키키 …"·"김키키씨 …"** 로 부른다(2026-09-30 사용자 요청). 모든 kk skill 설명 맨 앞에 이 부르는 말이 있어 요청 내용으로 알맞은 skill 이 뜬다. 이 문서는 ① 부르는 말을 읽는 규칙 ② 다른 skill 이 떴을 때 넘길 곳을 정한다.

## 1. 부르는 말 읽기
- **문장 맨 앞**의 "키키야"·"키키"·"김키키"·"김키키씨"(뒤따르는 쉼표·"궁금한 게 있어" 같은 말머리 포함)는 키키를 부르는 말이다 — **요청에서 빼고 읽는다.** 검색어·사람 이름·메일 발신자·참석자·과제 참여자로 쓰지 않는다.
  - "김키키씨 궁금한게 있어 휴가 규정이 어떻게 되?" → 요청 = 휴가 규정 (kk-wiki 검색어에 '김키키'를 넣지 않는다)
  - "김키키 ○○ 학회 메일은 이제 더이상 내가 못보게 자동스팸으로 분류해줘" → 요청 = ○○ 학회 메일 자동 스팸 (보낸 사람이 김키키인 메일이 아니다)
- 문장 **중간**에서 "김키키와·김키키가·김키키 박사"처럼 요청의 대상으로 나오는 이름은 사람 이름으로 읽는다(skill 문서 예시의 자리표시 이름 — README 사용 예시는 부르는 말과 겹치지 않게 '홍길동'을 쓴다). 애매하면 한 번 묻는다.
- 부르는 말만 있고 할 일이 없으면("키키야", "키키야 뭐 할 수 있어?") 아래 표의 7가지를 한 줄씩 소개하고 무엇을 할지 묻는다.
- 인사·머리표(🐱·😸 …)는 각 skill 규칙을 따른다 — 부르는 말에 대한 인사를 따로 붙이지 않는다.

## 2. 요청 → skill
| 이렇게 말하면 | skill |
|---|---|
| "세금계산서 처리하자", "여기 폴더 결제건들 지급신청하자", "영수증 처리해줘", "카드 명세서 RPA 로 올려줘" | **kk-pay** |
| "회의비 처리해줘", "이번 달 회의비", "회의록 써줘", "회의 녹음으로 회의록" | **kk-meet** |
| "두레이 드라이브에서 ~ 파일 찾아줘", "업무에서 ~ 찾아줘", "그 첨부 받아줘", "업무에 댓글 달아줘", "드라이브에 올려줘" | **kk-dry** |
| "~ 메일 찾아줘", "일주일 동안 온 메일 중 답장 안 한 거 골라줘", "○○ 학회 메일 자동 스팸으로", "~에게 메일 보내줘", "앞으로 ~ 메일은 ~ 폴더로" | **kk-mail** |
| "궁금한 게 있어, ~ 규정이 어떻게 돼?", "출장비 한도", "구매요구서 결재선", "이거 담당자가 누구야" | **kk-wiki** |
| "과제 예산 얼마 남았어", "재료비 잔액", "예산 정리해줘" | **kk-budget** |
| "검수신청 올려줘", "소액검수", "물품 검수" | **kk-inspect** |

넘기는 법: Claude Code 는 Skill 도구로 그 skill 을 부르고, Codex 는 그 skill 의 `SKILL.md` 를 읽어 따른다. 설치되지 않은 skill 이면 설치를 안내한다(`./install.ps1 <skill>`).

## 3. 헷갈리는 요청
- **세금계산서**: 지급신청(돈 지급)은 kk-pay. 물품 100만원 이상이면 검수신청(kk-inspect)이 먼저인지 kk-pay 가 확인한다.
- **회의비**: 지급신청이라도 kk-meet(회의비는 RPA 대상이 아니다). 회의비 **규정 질문**("사전결재 아직 필요해?", "1인 한도 얼마야?")은 kk-wiki.
- **메일 "정리"**: 답장 이야기가 있으면 kk-mail 기능 6(답장 안 한 메일 고르기) — 폴더 이동·스팸 같은 정리를 하지 않는다. 답장 이야기 없이 "받은편지함 정리"면 기능 2·4.
- **"자동 스팸으로"·"더 이상 안 보이게"**: kk-mail 기능 4 — 그 발신처 메일을 찾아 표 → 확인 → 스팸 신고(발신자 차단·지난 메일 소급). 폴더로 옮기라는 말이면 기능 3(자동분류 규칙).
- **Dooray 메일 vs 업무·드라이브**: 메일은 kk-mail, 업무 글·첨부·드라이브 파일은 kk-dry.
