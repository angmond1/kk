# 규정 변경표 — 옛 문서의 값을 현행 값으로 바꿔 읽기 (kk-wiki · kk-pay · kk-meet 공용)

위키 첨부·구버전 PDF(길라잡이 2024, 정부수탁 안내서 2022, 연구행정원 지침서 2021, 종합생활안내 2019)에는 바뀐 옛 값이 그대로 남아 있다.
`wiki_extract.py` 가 이 표의 **검색 패턴**으로 옛 값이 든 절을 찾아 frontmatter `stale_values` 에 적고, 답할 때는 **현행 값을 먼저** 쓰고 옛 값은
`(구버전 2021: 3만원)` 처럼 뒤에만 붙인다. 현행 값의 1차 근거는 항상 **위키 현행 페이지·포탈 공지**(계층 1)이며, 이 표는 그 요약이다.

- 확인 상태: **사용자** = 사용자가 직접 확인(2026-09-30) / **위키** = 위키 현행 페이지에서 확인 / **첨부** = 위키 첨부 문서에서 확인 / **공식** = 기관 공식 발표 확인 / **추정** = 확인 필요
- 새 변경을 알게 되면 행을 더하고(패턴은 옛 값 문구를 잡게), `python wiki_extract.py restale` 로 표시만 다시 매긴다(몇 초, 다시 추출하지 않음).
- ⚠ 표 칸 안의 `|` 는 반드시 `\|` 로 쓴다 — 그냥 `|` 는 칸 나눔으로 읽혀 그 행이 통째로 무시된다(2026-09-30 발견: 4행이 이 때문에 적용되지 않았음).
- 시행일이 확실하지 않으면 `미상` 으로 두고 지어내지 않는다. **값이 지급 유형·과제·부처마다 다른 규정은 한 줄로 '바뀌었다'고 적지 않는다** — 아래 '헷갈리기 쉬운 현행 값'.

## 헷갈리기 쉬운 현행 값 (바뀐 게 아님 — 구값으로 처리하지 말 것)
지급 유형·거주 구분·부처마다 값이 다른 규정. 위 표처럼 한 값으로 바꿔 읽지 말고, 질문의 조건(누구에게·무엇을·어느 과제)에 맞는 줄만 답한다.

- **원천세(사례비·자문료)** — 재무팀 「2. 지급신청 매뉴얼」(2026-09-15)·재무팀 행정위키 업데이트 비교표·RPA 전문가활용 안내(2025-11). Codex 검토(2026-09-30)로 정정: 20% 를 일반 규칙처럼 적었던 것은 틀림.
  - **국내 거주자 자문료·강연료**(전문가활용, 인적용역 기타소득, 34-671·17-671): 원천세구분 '외부인/기타소득(**8%**)'. 과세최저한 **12만 5천원** 초과 시 원천징수, 이하도 인적용역이라 원천세 정보는 입력. 국내 거주 외국인(183일 이상 거주 추정)도 거주자와 같다(매뉴얼 국외 거주자 Q1 예시).
  - **임상실험 피험자 사례비**(34-686): 5만원 초과 시 주민등록번호·주소 + 소득세(외부인/기타소득 **20%**) — 위 표 `clinical_honorarium`.
  - **국외 거주자(비거주자) 인적용역**: 조세조약을 맺지 않은 나라(대만·홍콩 등)는 '외부인(기타소득) **20%**'·원천세거주구분 '국외'. 외국에서 온라인·화상으로 한 자문은 국내 원천징수 비대상. 인적용역이 아닌 단순 교류로 초청한 비거주자의 항공료·체재비는 사례금으로 **22%** 원천징수 대상일 수 있음. 비거주자에게 회사가 직접 지급한 항공·숙박·식대는 비과세. **조세조약 면제 대상 나라** 거주자가 한국에 와서 한 자문은 서류(거주자증명서·전문가활용신청서·여권)를 내면 면제, 빠지면 같은 '외부인 기타소득 20%'(지방세 포함 22%) — 위 표 `nonresident_exemption_docs`(2026-09-29 공지).
  - **직원**: 근로소득(10%)(RPA 안내).
- **식대 1인 한도**: 회의비(식대+다과) 5만원(원 기준). **야근식대**는 과기정통부·산업부 등 5만원, 중기부·서울시 등 **3만원** — 이 3만원은 구값이 아니다.
